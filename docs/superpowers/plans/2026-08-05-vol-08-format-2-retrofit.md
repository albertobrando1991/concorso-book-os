# VOL-08 Format 2 Retrofit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert all 13 M-TR01 chapters to ConcorsoBook format 2, rerun pipeline gates 08-23, and leave VOL-08 in `ready_for_human_signoff` with step 24 incomplete.

**Architecture:** First add a tested, auditable `pipeline reopen` command so the CLI remains the sole owner of `run-state.json`. Then process each declared chapter as one reviewable unit through steps 08-12, reconcile the module through steps 13-18, and validate the commercial volume through steps 19-23. The Book Studio renderer remains unchanged: analytical numbering must come from real Nucleo IDs in the chapter sources.

**Tech Stack:** TypeScript 5.7, Node.js 20+, Vitest 2.1, ConcorsoBook pipeline CLI, Markdown/YAML frontmatter, Book Studio/Next.js 15, Playwright.

## Global Constraints

- Never edit `pipeline/VOL-08/run-state.json` by hand; use `next`, `gate`, `complete`, `sync`, and the new tested `reopen` command.
- Preserve valid human text and consolidated source traceability; never write reader text from `wiki/raw/`.
- Read the exact prompt generated by `pipeline next` before every LLM step.
- Call `LocalAgentMemory` with scope `VOL-08` before each LLM step and capture a concise trace afterward.
- A format 2 chapter declares `format_version: 2`, has at least five Nucleo IDs, at least 600 words per nucleus unless the CLI contract is stricter, at least six commented quizzes, and a reasoned case.
- Use `▣ Verifica` every 5-7 nuclei and keep quizzes, cases, tables, and boxes printable at KDP 6.69 x 9.61 in.
- `parziale`, `solo-nominato`, and `mancante` are not publishable; `rinviato` requires a precise, existing, complete destination.
- Open step 11 before Humanizer changes so the pipeline records the pre-Humanizer snapshot.
- Do not use `--accept` for implemented gates or to hide a blocker.
- Keep VOL-03 and shared memory changes out of editorial/code commits by staging explicit paths only.
- Do not commit or push step 24 as complete; final target is `ready_for_human_signoff`.
