# Pacchetto per review epidemiologica indipendente

## 1. Scopo e regola di indipendenza

Il pacchetto consente a un revisore esterno al flusso di redazione di controllare, in modo riproducibile, la batteria su epidemiologia e screening e lo scenario di risposta a un segnale epidemiologico. Non costituisce un giudizio favorevole e non autorizza ancora la scrittura dei capitoli.

Il revisore deve dichiarare:

- nome, qualifica pertinente, organizzazione o attività professionale;
- assenza di partecipazione alla redazione dei materiali controllati;
- eventuali conflitti di interesse professionali, economici o istituzionali;
- data della review e riferimento verificabile della firma o approvazione.

La verifica editoriale interna può preparare dati e modelli, ma non può sostituire questa attestazione.

## 3. Sequenza obbligatoria

1. Compilare identità, indipendenza e conflitti nel verbale.
2. Ripetere i 20 controlli della sezione 4 senza consultare la chiave della sezione 5.
3. Registrare formula, risultato non arrotondato, arrotondamento e giudizio.
4. Confrontare i risultati con la chiave editoriale.
5. Verificare fonti, versioni, significato epidemiologico e limiti con la checklist della sezione 6.
6. Registrare ogni rilievo nella tabella errori del verbale, anche se poi risolto.
7. Esprimere il giudizio di pubblicabilità solo dopo la chiusura dei rilievi.

## 6. Checklist epidemiologica specialistica

Per ogni voce il revisore indica `conforme`, `non conforme`, `non applicabile` oppure `da verificare`, con posizione e fonte.

| ID | Controllo | Esito | Evidenza/note |
| --- | --- | --- | --- |
| E01 | Fonte ufficiale, anno, popolazione e versione del dato sono identificabili. |  |  |
| E02 | Le stime PASSI pesate non sono presentate come conteggi amministrativi osservati. |  |  |
| E03 | Punti percentuali, variazione relativa, rapporto e rischio relativo sono distinti. |  |  |
| E04 | Numeratore, denominatore, esclusioni e periodo di riferimento sono espliciti. |  |  |
| E05 | Arrotondamenti e scarti fra componenti non sono forzati o occultati. |  |  |
| E06 | La non sovrapposizione degli intervalli non è trasformata in un test non eseguito. |  |  |
| E07 | Confronti geografici o temporali non sono interpretati automaticamente come causali. |  |  |
| E08 | La definizione operativa di caso contiene persona, luogo, tempo e criterio clinico. |  |  |
| E09 | Criteri di laboratorio e collegamento epidemiologico sono aggiunti solo se disponibili. |  |  |
| E10 | La definizione operativa del focolaio resta distinta dalla definizione ufficiale di sorveglianza. |  |  |
| E11 | `potenziale/conclamato` del flusso PREMAL non è confuso con `possibile/probabile/confermato`. |  |  |
| E12 | Il segnale è verificato per duplicati, baseline, stagionalità e cambiamenti diagnostici. |  |  |
| E13 | Line list, minimizzazione dei dati e canali protetti sono trattati correttamente. |  |  |
| E14 | Disegno di studio, tassi d'attacco e RR sono coerenti con la coorte ricostruita. |  |  |
| E15 | Non risposta, ricordo, misclassificazione, confondimento ed esposizioni correlate sono discussi. |  |  |
| E16 | Evidenze epidemiologiche, microbiologiche e ambientali non sono considerate intercambiabili. |  |  |
| E17 | Le misure precauzionali proporzionate non attendono necessariamente la prova eziologica definitiva. |  |  |
| E18 | Ruoli, modulistica e provvedimenti locali non sono presentati come uniformi sul territorio nazionale. |  |  |
| E19 | Comunicazioni e rapporto finale separano fatti, ipotesi, incertezze e azioni. |  |  |
| E20 | La pagina PREMAL corrente e la definizione ufficiale specifica applicabile sono ricontrollate alla data della review. |  |  |

## 7. Criteri di accettazione

La review può essere favorevole soltanto se:

- tutti i 20 controlli quantitativi sono riprodotti entro l'arrotondamento dichiarato;
- non restano errori gravi aperti;
- ogni rilievo medio è corretto oppure motivatamente accettato e tracciato;
- fonte, versione e data di ciascun dato ufficiale sono confermate;
- sono verificati il flusso PREMAL corrente e la definizione ufficiale specifica pertinente;
- sono documentate indipendenza, qualifica, conflitti, data e approvazione del revisore;
- il verbale contiene link o riferimenti sufficienti a ripetere la verifica.

## 8. Esito nella pipeline

Il revisore compila il verbale `wiki/reviews/pipeline/VOL-07/07-verbale-review-epidemiologica-indipendente-m-sa02.md`. Un verbale vuoto, non firmato o privo di evidenze mantiene `SA02-06` parziale e lo step 07 bloccato.

Un giudizio favorevole consente soltanto di proporre la chiusura di `SA02-06` e di rieseguire il gate. Non sana automaticamente gli altri blocchi del modulo e non equivale, da solo, ad autorizzazione a scrivere i capitoli.
