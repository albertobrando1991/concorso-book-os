# Checklist per review di igiene a letto e trasferimenti

## 1. Scopo e limite d'uso

Questo documento organizza il confronto professionale sulle sequenze di igiene completa a letto e trasferimento letto-carrozzina. È una risorsa di pianificazione: non è un protocollo clinico, non sostituisce addestramento pratico, istruzioni dei dispositivi, valutazione individuale o procedura aziendale.

Le caselle sono intenzionalmente vuote. La predisposizione della checklist non equivale a validazione. Prima dell'uso editoriale servono revisore qualificato, controllo delle fonti correnti e prova pratica nel setting pertinente.

## 6. Trasferimento letto-carrozzina

Prima di valutare i gesti, il revisore deve confermare il percorso decisionale: persona autonoma, parzialmente collaborante o non collaborante; ausilio minore, asse, cintura o sollevatore; uno o più operatori; eventuale competenza fisioterapica e procedura locale.

| ID | Elemento da validare | Fonte | Esito | Evidenza/correzione |
| --- | --- | --- | --- | --- |
| T01 | Fattibilità, restrizioni, carico consentito, controllo del tronco e collaborazione sono valutati. | `UPD-T`, `INAIL` |  |  |
| T02 | Il trasferimento manuale è escluso quando rischio, peso, collaborazione o condizioni richiedono ausilio/sollevatore. | `INAIL`, `UPD-S` |  |  |
| T03 | Carrozzina e letto sono controllati per freni, pedane, braccioli, altezza e spazio. | `UPD-T` |  |  |
| T04 | Calzature e appoggio dei piedi sono adeguati. | `UPD-T` |  |  |
| T05 | Accessi, cateteri, drenaggi, linee e altri dispositivi non sono messi in trazione. | review professionale |  |  |
| T06 | Il passaggio alla seduta sul bordo letto favorisce la collaborazione e protegge operatore e persona. | `UPD-T` |  |  |
| T07 | In seduta sono valutati equilibrio, capogiri e segni di intolleranza prima di proseguire. | `UPD-T` |  |  |
| T08 | Comandi e conteggio coordinano i partecipanti; il numero di operatori è adeguato. | `UPD-T`, `UPD-S` |  |  |

## 7. Punti critici da non approvare per inerzia

| ID | Punto | Domanda al revisore | Esito/evidenza |
| --- | --- | --- | --- |
| C01 | Temperatura dell'acqua `43-46 °C` indicata in `UPD-B` | È compatibile con protocollo corrente, sensibilità, perfusione e rischio di ustione della persona? |  |
| C02 | Massaggio dorsale con lozione in `UPD-B` | Deve essere eliminato o limitato alla luce della prevenzione delle lesioni da pressione? |  |
| C03 | Movimenti distale-prossimale con razionale circolatorio | Il razionale è aggiornato e applicabile a tutte le condizioni vascolari? |  |
| C04 | Uso di sapone, talco, deodoranti e creme | Quali prodotti sono ammessi e quali controindicazioni vanno esplicitate? |  |
| C05 | Uno o due operatori per il bagno | Quali criteri oggettivi determinano il numero necessario? |  |
| C06 | Mani della persona sulle spalle dell'operatore e presa al girovita | La tecnica è ammessa dalla procedura ergonomica corrente o va sostituita? |  |
| C07 | Cintura di trasferimento | Chi può usarla, con quale formazione e quali controindicazioni? |  |
| C08 | Trasferimento della persona non collaborante | Quando il sollevatore è obbligatorio e quando servono due o più operatori? |  |
| C09 | Imbragatura del sollevatore | Come si verificano taglia, integrità, attacchi e compatibilità secondo `SLING-UNI`, `BIRDIE-EVO` e il dispositivo realmente presente? |  |
| C10 | Attribuzione all'OSS | Quali fasi richiedono pianificazione, supervisione o intervento dell'infermiere/fisioterapista nel setting considerato? |  |

## 8. Criteri di accettazione

La checklist può essere proposta per l'uso editoriale soltanto se:

- il revisore è qualificato e dichiara ruolo e conflitti;
- tutti i punti `A`, `I`, `T` e `C` hanno esito ed evidenza;
- nessun errore grave o dubbio di sicurezza resta aperto;
- le indicazioni sono confrontate con almeno una procedura aziendale corrente e con i manuali degli ausili richiamati;
- sono esplicitati criteri di interruzione, escalation, numero di operatori e limiti professionali;
- ogni specificità locale è etichettata e non trasformata in regola nazionale;
- una prova pratica controllata conferma comprensibilità e sicurezza della futura stazione.

## 9. Esito nella pipeline

La compilazione favorevole riduce il blocker della riga Infermiere/OSS, ma non chiude automaticamente lo step 07. Il revisore deve registrare rilievi, correzioni e giudizio in un verbale professionale; la matrice resta `parziale` finché tale review non è acquisita e gli altri nuclei non sono completi.
