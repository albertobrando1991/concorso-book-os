# Urbanistica e governo del territorio

## Sintesi

Il governo del territorio coordina usi, trasformazioni, infrastrutture, servizi e tutele. Il sistema è multilivello: principi e discipline nazionali convivono con legislazione regionale, pianificazione territoriale e strumenti comunali.

## Distinzioni

| Concetti | Differenza |
| --- | --- |
| piano generale / attuativo | regola l’assetto complessivo / precisa l’attuazione di un ambito |
| destinazione urbanistica / titolo edilizio | disciplina d’uso del suolo / legittimazione del singolo intervento |
| standard / parametro edilizio | dotazioni territoriali / misura riferita all’edificazione |
| vincolo urbanistico / paesaggistico | scelta di piano / tutela derivante da disciplina autonoma |
| conformità urbanistica / compatibilità paesaggistica | coerenza con il piano / rispetto dei valori tutelati |
