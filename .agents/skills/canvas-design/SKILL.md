# Canvas Design

Use this skill when a task requires original static visual design or a professional review and refinement of an existing image. It is especially suited to the assets of ConcorsoBook OS: diagrams, chapter maps, visual protocols, workbook cards and print-ready illustrations.

## Non-negotiable output rules

- Create only `.md`, `.png` and `.pdf` deliverables.
- Create original work; never copy a living artist, an existing book design or a copyrighted composition.
- Preserve the meaning, pedagogy and approved editorial language of the source asset. Do not alter legal or instructional content merely to decorate it.
- Keep all words sparse, intentional and proofread. Use visual hierarchy, form, space, symbols and colour to communicate before prose.
- Keep every element inside the canvas with safe margins; no clipping, collision, overlap or illegible microtext.

## Two-step workflow

### 1. Create the visual philosophy

Before drawing, write a design philosophy as a `.md` file. Name the movement in one or two words and write four to six concise paragraphs. The philosophy must define:

- space and form;
- colour and material;
- scale and rhythm;
- composition and balance;
- visual hierarchy and the role of minimal text.

Treat it as a manifesto for an aesthetic movement, not as a page template. Make clear that the final artifact is a visual object: information is carried by composition, shape, image, pattern and spatial relationships rather than explanatory paragraphs. Repeatedly require meticulous craft, painstaking attention, deep expertise and master-level execution, while leaving enough interpretive room for a fresh, original outcome.

### 2. Express the philosophy on canvas

Identify the subtle conceptual thread in the source material. It is the quiet DNA of the composition, never a literal slogan: knowledgeable readers may recognise it, while every reader should still encounter a complete and compelling visual work.

Create one highly visual page unless the user explicitly requests multiple pages. Prefer ordered repetition, grids, layered marks, controlled systems, symbols and a restrained palette. Use typography only as a visual accent. The artifact should feel like a rigorously observed diagram from an imaginary discipline: analytical enough to be trustworthy, expressive enough to feel human.

For ConcorsoBook OS, respect the editorial system: warm ivory or white ground, disciplined contrast, legible navy/bordeaux/charcoal accents where appropriate, workbook clarity, and print-safe rendering for KDP 6.69 x 9.61 in. Diagram images must retain large visual anchors, clear paths and roomy negative space at paperback scale.

## Image-audit and optimisation protocol

When refining an existing asset or a set of chapter images:

1. Inspect it at its intended display size and in the Book Studio preview.
2. Check text accuracy, contrast, reading order, crop safety, alignment, whitespace, repetition, image-to-caption relationship and compatibility with adjacent blocks.
3. Check that figures are not consecutive without a textual or structural reason; distribute them beside the idea they explain.
4. For workbook tables and exercises, prioritise readable fields over density. On paperback pages, split dense grids into separate tables rather than shrinking type or forcing more than three compact columns.
5. Preserve a consistent palette, stroke language, icon system and image ratio across the chapter and the wider volume.
6. Refine rather than decorate: remove visual noise, correct spacing, rebalance scale and make existing elements more precise. Do not add graphics merely to make the page busier.
7. Validate the final result: no image or caption overflow, no broken asset path, no overlap, no cropped text and no accidental low-resolution result.

## Craft standard

The final result must feel meticulously crafted, laboured over with care and executed at master level. It should look like the product of countless deliberate refinements by an expert designer. Before delivery, make a second pass focused only on precision: alignment, margins, visual rhythm, typographic restraint, colour calibration and coherence. If an element does not strengthen the composition, simplify or remove it.
