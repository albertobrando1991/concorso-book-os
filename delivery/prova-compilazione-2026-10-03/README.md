# Prova di compilazione — volume 12

Il PDF contiene le pagine 127 e 128 dell'interno di 492 pagine già revisionato. Le pagine sono estratte senza ridimensionare né modificare contenuti o campi.

Stampare in **dimensioni effettive / 100%**, disattivando «adatta alla pagina». Il formato della pagina PDF è circa 170 × 244 mm. Se si usa un foglio A4, lasciare i margini esterni aggiuntivi: non ingrandire il contenuto per riempirlo.

Compilare a penna i campi con dati di esercizio, verificando spazio disponibile, leggibilità delle etichette e possibilità di annotare una risposta completa. Registrare nel riscontro data, scala di stampa e campi eventualmente insufficienti. Il controllo dell'estrazione digitale è già eseguito; l'esito a penna resta da acquisire.
