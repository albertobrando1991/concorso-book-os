### Schema 22.6 — La settimana vista dai risultati

Settimana tipo orientata agli output


| Giorno | Sequenza di lavoro |
|---|---|
| Lunedì | Base comune → richiamo → 10 domande. |
| Martedì | Modulo → quiz mirati → diario degli errori. |
| Mercoledì | Ripasso → caso o orale → risposta breve. |
| Giovedì | Base comune → allenamento sugli errori → flashcard. |
| Venerdì | Modulo → simulazione parziale → correzione. |
| Sabato | Simulazione → revisione → tagli e priorità. |
| Domenica | Ripasso leggero → pianificazione → nuova settimana. |

È una settimana esemplificativa: adatta giorni e durata alle ore reali. Se il tempo diminuisce, riduci i blocchi mantenendo output e diario nel ciclo.
