### Schema 10.4 — Infrastruttura, servizi e strumenti

Internet, Web e protocolli: browser, DNS, server, posta e cloud su livelli diversi della rete.


Internet è l'infrastruttura di rete; Web, posta elettronica e servizi cloud la utilizzano con funzioni diverse. Nella navigazione, il browser dell'utente richiede risorse a un server web; il DNS permette di risolvere il nome di dominio in un indirizzo IP.

| Elemento | Funzione |
|---|---|
| Browser, app o client | Strumento usato dall'utente per accedere al servizio. |
| Server web | Rende disponibili pagine, risorse e API. |
| HTTP/HTTPS | Protocolli impiegati per le risorse del Web. |
| SMTP/IMAP | Protocolli della posta elettronica con funzioni diverse. |
| TCP/IP | Protocolli di trasporto e rete. |
| URL | Individua una risorsa sul Web. |

Browser, motore di ricerca, Web e Internet vanno distinti: sono rispettivamente un programma, un servizio di ricerca, un insieme di servizi e l'infrastruttura che li collega.
